about=Professional QGIS plugin to download enriched Italian cadastral parcels via the free Zornade API v2 (100%% free, 1,000 req/hour). Search by GPS coordinates, map canvas bounding box (adaptive quadtree subdivision), or cadastral reference (Belfiore municipality code, sheet, parcel). Each parcel includes 35 attribute fields: accurate geometry (Polygon/MultiPolygon), CORINE land cover classification, seismic zone (1–4), PGA, flood and landslide level, subsidence analysis (velocity, risk class, direction), OMI real estate valuation (purchase and rental ranges), cadastral data (foglio, sezione urbana, CAP). Sketching: categorized renderer for CORINE land cover (5 Level-1 classes), seismic zone (4 classes), and subsidence risk (5 classes). Scale-dependent labeling. Native Qt6 interface with geocoding, map picking, async download via QgsTask with retry logic. Free API tokens at app.zornade.com.
